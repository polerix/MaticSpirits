# MaticSpirits

Server-backed Matic Spirit generator portal with three faction skins, one-of-one serial generation, a rock-paper-scissors duel, and a searchable turnaround vault.

## Local Run

```bash
npm start
```

Default local address:

```text
http://127.0.0.1:4176
```

## Notes

- The live portal requires the local Node server in `server.js`.
- Static hosting can show the included `under-construction.html` landing page, but it will not run the serial-backed generator without the server.
